# Sistema de Gestión de Repuestos - Transervice

El proyecto consiste en implementar un sistema informático para la gestión y control de inventario de repuestos automotrices en **Transervice**, una empresa dedicada al desarme y venta de piezas de vehículos.  
El sistema combina un dashboard web con herramientas de hardware como impresoras térmicas, códigos QR y teléfonos Android para optimizar el registro, ubicación y consulta de piezas dentro del inventario.

## Objetivo General
Desarrollar e implementar un sistema eficiente de gestión de repuestos para Transervice:
+ Agilizar el ingreso y registro de piezas provenientes del desarme.  
+ Mejorar el control y trazabilidad del inventario a través de identificación única por QR.  
+ Aumentar la visibilidad y rotación de stock mediante registro organizado y consulta rápida.  
+ Reducir errores, extravíos y pérdidas operativas dentro del almacén.  

## Características principales
- Dashboard web responsivo (móvil-friendly).  
- CRUD de piezas y vehículos.  
- Generación de etiquetas térmicas con QR.  
- Consulta en tiempo real de disponibilidad.  
- Registro fotográfico de piezas.  
- Búsqueda por categoría, compatibilidad, marca o vehículo.  

## Tecnologías utilizadas
- **Backend:** Django (Python)  
- **Base de datos:** PostgreSQL  
- **Frontend:** HTML / CSS / Bootstrap  
- **Hardware:** impresora térmica, teléfonos Android para captura y registro  
- **Control de versiones:** Git & GitHub
