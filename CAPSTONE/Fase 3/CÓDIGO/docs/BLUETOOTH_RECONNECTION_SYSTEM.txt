# Sistema de Reconexión Bluetooth Inteligente
## Documentación Técnica

### Arquitectura

El sistema implementa **detección progresiva de capacidades** del navegador con 3 estrategias de persistencia:

#### 1. **Reconexión Automática Silenciosa (Tier 1)**
- **API**: `navigator.bluetooth.getDevices()` (Chrome 85+, Edge 85+)
- **Comportamiento**: 
  - Auto-reconexión en background al recargar la página
  - Sin diálogos de usuario
  - Backoff exponencial en caso de desconexión: 100ms, 200ms, 400ms, 800ms, 1600ms
- **Ventajas**: 
  - UX profesional (invisible para el usuario)
  - Persiste entre sesiones del navegador
  - Reconexión automática tras desconexiones inesperadas
- **Limitaciones**: 
  - Requiere que el usuario haya autorizado el dispositivo previamente
  - Solo funciona con dispositivos en la lista de autorizados

#### 2. **Notificación Manual Discreta (Tier 2 - Fallback)**
- **API**: `Web Bluetooth API` estándar
- **Comportamiento**:
  - Muestra notificación flotante elegante al detectar desconexión
  - Botón de reconexión con un clic
- **Ventajas**:
  - Compatible con navegadores sin `getDevices()`
  - UX profesional con feedback visual claro
- **Implementación**:
  ```javascript
  showReconnectNotification(deviceName) {
    // Notificación Bootstrap alert en esquina inferior derecha
    // Con botón de reconexión de un clic
  }
  ```

#### 3. **Conexión Manual (Tier 3 - Base)**
- **API**: `navigator.bluetooth.requestDevice()`
- **Comportamiento**: Botón "Conectar" en navbar
- **Ventajas**: Universalmente compatible

### Componentes del Sistema

#### 1. **bluetooth-printer-manager.js**
**Responsabilidad**: Lógica de negocio y gestión de conexión

**Características principales**:
- Detección automática de capacidades del navegador
- Reconexión con backoff exponencial
- Gestión de estado persistente (localStorage)
- Sistema de callbacks para notificaciones de estado
- Integración con BroadcastChannel para hub opcional

**API Pública**:
```javascript
window.printerManager = {
  // Propiedades
  capabilities: {
    bluetooth: boolean,
    getDevices: boolean,
    broadcastChannel: boolean
  },
  
  // Métodos principales
  connect(): Promise<{success, deviceName}>,
  reconnect(): Promise<{success}>,
  disconnect(): void,
  isConnected(): boolean,
  getDeviceName(): string,
  getStatus(): {connected, deviceName, deviceId},
  
  // Impresión
  printLabel(imageUrl, autoReconnect=true): Promise<{success}>,
  testPrint(): Promise<{success}>,
  
  // Callbacks
  onStatusChange(callback): void,
  
  // Hub (opcional)
  imprimirViaHub(urlEtiqueta): Promise<{enviado}>
}
```

**Estados posibles**:
- `connecting`: Iniciando conexión
- `connected`: Conectado y listo
- `reconnecting`: Reconectando automáticamente
- `disconnected`: Desconectado
- `printing`: Imprimiendo en progreso
- `printed`: Impresión completada
- `error`: Error en operación

#### 2. **bluetooth-status-indicator.js**
**Responsabilidad**: Indicador visual animado en navbar

**Características**:
- Diseño profesional con iconos Font Awesome
- Animaciones suaves (pulse, spin, shake)
- Colores semánticos (Bootstrap):
  - Gris: Desconectado
  - Amarillo: Conectando
  - Verde: Conectado
  - Azul cian: Reconectando
  - Azul: Imprimiendo
  - Rojo: Error
- Responsive (oculta texto en mobile)
- Auto-inserción en navbar

**Estados visuales**:
```css
.status-disconnected  -> Icono gris estático
.status-connecting    -> Icono amarillo pulsante
.status-connected     -> Icono verde estático
.status-reconnecting  -> Icono azul giratorio
.status-printing      -> Icono azul pulsante rápido
.status-error         -> Icono rojo con shake
```

#### 3. **bluetooth-printer.js**
**Responsabilidad**: Cliente de bajo nivel Web Bluetooth API

**No modificado** - Implementación base de comunicación GATT/ESC-POS

### Flujos de Uso

#### Flujo 1: Primera Conexión (Usuario Nuevo)
```
1. Usuario carga página → No hay conexión previa
2. Ve botón "Conectar" en navbar
3. Clic en "Conectar" → Diálogo nativo de Bluetooth
4. Selecciona "GOOJPRT PT210"
5. Dispositivo se guarda en localStorage + lista de autorizados del navegador
6. Indicador visual muestra "Conectado" (icono verde)
7. Botón "Conectar" se oculta automáticamente
```

#### Flujo 2: Reconexión Automática (Usuario Recurrente con getDevices)
```
1. Usuario recarga página
2. Sistema detecta capacidad getDevices() ✓
3. Auto-reconexión silenciosa en background
4. Indicador muestra "Reconectando..." (icono azul giratorio)
5. Conexión GATT exitosa
6. Indicador cambia a "Conectado" (icono verde)
7. Toast de confirmación: "Reconectado automáticamente"
```

#### Flujo 3: Reconexión Manual (Usuario Recurrente sin getDevices)
```
1. Usuario recarga página
2. Sistema detecta capacidad getDevices() ✗
3. Muestra notificación flotante: "Impresora desconectada - GOOJPRT PT210"
4. Botón "Reconectar" en notificación
5. Usuario hace clic → Conexión sin diálogo (usa dispositivo guardado)
6. Indicador cambia a "Conectado"
```

#### Flujo 4: Desconexión Inesperada con Auto-Recuperación
```
1. Impresora conectada (icono verde)
2. Cable USB desconectado o Bluetooth fuera de rango
3. Evento 'gattserverdisconnected' disparado
4. Sistema inicia backoff exponencial:
   - Reintento 1: 100ms
   - Reintento 2: 200ms
   - Reintento 3: 400ms
   - Reintento 4: 800ms
   - Reintento 5: 1600ms
5. Si todos fallan → Muestra notificación de reconexión manual
6. Indicador en rojo: "Error"
```

#### Flujo 5: Impresión
```
1. Usuario crea pieza en formulario
2. Clic en "Imprimir Etiqueta"
3. Sistema verifica conexión:
   - Si conectado → Imprime directamente
   - Si desconectado → Auto-reconecta primero
4. Indicador muestra "Imprimiendo..." (azul pulsante)
5. Datos enviados en chunks de 512 bytes
6. Indicador cambia a "Impreso ✓" por 2 segundos
7. Vuelve a "Conectado"
```

### Configuración y Personalización

#### Ajustar Límite de Reintentos
```javascript
// En bluetooth-printer-manager.js constructor
this.maxReconnectAttempts = 5;  // Cambiar según necesidad
```

#### Ajustar Delays de Backoff
```javascript
// En scheduleExponentialBackoffReconnect()
const delay = Math.pow(2, this.reconnectAttempts) * 100;
// Multiplicador 100ms = delays: 100, 200, 400, 800, 1600
// Multiplicador 200ms = delays: 200, 400, 800, 1600, 3200
```

#### Personalizar Colores del Indicador
```css
/* En bluetooth-status-indicator.js addStyles() */
.bluetooth-status-indicator.status-connected .status-icon {
  background: rgba(40, 167, 69, 0.3);  /* Verde Bootstrap */
}
```

#### Deshabilitar Auto-Reconexión
```javascript
// En bluetooth-printer-manager.js constructor
// Comentar esta línea:
// this.initializeReconnectionStrategy();
```

### Debugging

#### Ver Estado del Sistema
```javascript
// En consola del navegador
console.log('Capacidades:', window.printerManager.capabilities);
console.log('Conectado:', window.printerManager.isConnected());
console.log('Estado:', window.printerManager.getStatus());
```

#### Forzar Reconexión
```javascript
await window.printerManager.reconnect();
```

#### Ver Dispositivos Autorizados
```javascript
const devices = await navigator.bluetooth.getDevices();
console.log('Dispositivos:', devices.map(d => ({id: d.id, name: d.name})));
```

#### Limpiar Estado Guardado
```javascript
localStorage.removeItem('bluetoothPrinterConnected');
localStorage.removeItem('bluetoothPrinterDevice');
location.reload();
```

### Mejores Prácticas

1. **No llamar `connect()` en bucle** - Usa el sistema de reconexión automática
2. **Verificar `isConnected()` antes de imprimir** - O habilitar `autoReconnect=true`
3. **No desconectar manualmente** a menos que el usuario lo solicite
4. **Escuchar eventos de estado** para actualizar UI
5. **Respetar límite de reintentos** - No saturar el dispositivo Bluetooth

### Solución de Problemas Comunes

#### "API getDevices no disponible"
- **Causa**: Navegador antiguo (< Chrome 85)
- **Solución**: Sistema usa automáticamente notificación manual

#### "Dispositivo no encontrado en lista de autorizados"
- **Causa**: Usuario nunca autorizó el dispositivo o borró datos del navegador
- **Solución**: Botón "Conectar" permite re-autorizar

#### "No se pudo reconectar. Máximo de reintentos alcanzado"
- **Causa**: Impresora apagada o fuera de rango
- **Solución**: Usuario debe acercar impresora o encenderla, luego clic en notificación

#### Indicador no aparece en navbar
- **Causa**: Navbar no existe o estructura HTML diferente
- **Solución**: El indicador se agrega a `document.body` como fallback
